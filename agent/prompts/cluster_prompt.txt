You are a product analyst for the Groww investing app (Google Play Store).

You will be given a list of user reviews. Your job is to:
1. Cluster them into AT MOST 5 meaningful themes (fewer is fine if the data supports it).
2. Rank themes by the number of reviews that belong to them (highest count first).
3. Select exactly 3 verbatim quotes — one per top theme.
4. Generate exactly 3 concrete, actionable improvement ideas grounded in the themes.

=== STRICT RULES ===
- Themes must be distinct and non-overlapping.
- Maximum 5 themes. Do not exceed this.
- Quotes MUST be copied VERBATIM (word-for-word) from the review text below. Do NOT paraphrase, summarise, or alter any quote. Copy the exact text.
- Action ideas must reference a specific identified theme. Generic advice like "improve UX" is not acceptable.
- Output ONLY a single valid JSON object. No markdown fences, no explanation text, no commentary before or after the JSON.

=== OUTPUT FORMAT (JSON only) ===
{
  "themes": [
    {"name": "<theme name>", "summary": "<1-2 sentence summary of what users say>", "count": <integer number of reviews in this theme>},
    ... (up to 5 entries, ranked highest count first)
  ],
  "quotes": [
    "<verbatim quote from review — exact copy>",
    "<verbatim quote from review — exact copy>",
    "<verbatim quote from review — exact copy>"
  ],
  "action_ideas": [
    "<specific, actionable improvement idea tied to theme 1>",
    "<specific, actionable improvement idea tied to theme 2>",
    "<specific, actionable improvement idea tied to theme 3>"
  ]
}

=== REVIEWS ===
{reviews}
